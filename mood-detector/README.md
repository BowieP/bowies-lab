# 🌟 Bowie's Mood Predictor

A super smart, all-in-one web app that guesses how you are feeling based on your stories, thoughts, or adventures!

## 🚀 About the Project
Have you ever wanted to tell a story and see if a computer can figure out your mood? This project is a fun way to do just that. Using a custom logic engine, it analyzes your input, matches it against a library of moods, and predicts your current vibe—complete with custom vector graphics!

## ✨ Features
*   **Intelligent Analysis:** It doesn't just look for words; it understands the vibe of your sentences.
*   **20+ Moods:** From happy and excited to adventurous and creative!
*   **Vector Art:** Crisp, clean SVG icons for every mood.
*   **Responsive Design:** Looks great on your computer, tablet, or phone.
*   **Fun & Friendly:** Designed to be easy to read and super positive.

## 🛠️ How it Works
1.  **Input:** Type whatever you are doing or how you are feeling into the text box.
2.  **Analyze:** The predictor scans your words, adjectives, and adverbs.
3.  **Result:** It returns a matching mood, a friendly message, and a unique vector icon.
4.  **No Dead Ends:** If it isn't sure, it asks you to tell it more!

## 💻 Tech Stack
*   **HTML5:** Structure for your thoughts.
*   **CSS3:** Styled for a modern, professional look (using the *Fredoka One* font).
*   **Vanilla JavaScript:** The brain behind the prediction logic.
*   **SVG:** Scalable vector icons built directly into the code.

## 🎨 How to Run
1.  Download the `index.html` file.
2.  Double-click the file to open it in your favorite web browser.
3.  Start sharing your day and see what the app thinks!
**Note: this is not AI. It just checks your string against a libary of keywords.**
